# Portfolio: Сайт-портфолио фотографа

Адаптивная верстка, перенесенная на WordPress с глубокой интеграцией кастомных полей (ACF) для гибкого управления контентом.

## 🚀 Выполненные задачи

### 1. Интеграция с WordPress
* Перенос статической HTML-верстки на PHP-шаблоны WordPress (`front-page.php`, `header.php`, `footer.php`).
* Разработка модульной структуры темы с использованием `get_template_part` и кастомных функций рендеринга секций.
* Оптимизация стандартного цикла WordPress (удаление лишнего вывода контента для кастомных лендингов).

### 2. Управление контентом (ACF)
* Полная интеграция **Advanced Custom Fields**: создание гибких полей для Hero-секции, галерей и текстовых блоков.
* Реализация динамической галереи: данные (изображения, alt-теги, мета-информация) подтягиваются из групп полей ACF.

### 3. Оптимизация и Performance
* **Изображения:** Внедрена поддержка современных форматов **AVIF** и **WebP** через тег `<picture>` с автоматическим фолбэком.
* **Чистый код:** Настройка `functions.php` для отключения лишних надстроек WordPress (генерация scaled-копий, сжатие JPEG) для сохранения качества графики.

## 🛠 Технологии
* **CMS:** WordPress
* **Frontend:** HTML5 (Semantic), CSS3 (Flexbox/Grid), Native JavaScript (ES6+), PHP
* **Plugins:** Advanced Custom Fields (ACF)
* **Tools:** Git/GitHub, MAMP, Local by Flywheel
